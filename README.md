# Save The Ball
a game about being a ball running away from other balls.

# How to Play
**Windows**
1. Download the latest release as a `.exe`.
2. Run the `.exe` file.

**macOS/Linux**
1. Download the latest release as a `.love`.
2. Ensure LÖVE2D and Lua is installed.
3. Run the `.love` file.

# Virus detection
Because this game isn't downloaded often and isn't recognised by your browser or antivirus, it may be flagged as a virus, however you can check this for yourself at VirusTotal.
If you would like to see a scan that's already been done, look in the latest release and there will be a link to the VirusTotal scan
